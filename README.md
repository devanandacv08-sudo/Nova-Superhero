# ✦ NOVA — The Unlimited You

A futuristic AI superhero website created for the **TechAscent Machine Test**.

##  About NOVA

NOVA is an original AI superhero designed to help people discover their own potential.

> “The superhero isn't someone else. It's you — with a little extra power.”

##  NOVA Powers

-  THINK — Think through problems clearly
-  LEARN — Learn concepts step by step
-  CREATE — Turn ideas into creative possibilities
-  BUILD — Build websites, apps and projects
-  TALK — Have a natural conversation with NOVA

##  Features

- Futuristic galaxy-themed interface
- Interactive superhero experience
- Animated story section
- AI-powered NOVA chatbot
- Multiple NOVA modes
- Interactive mini-games
- Responsive website design

##  Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenAI API

## Mission

NOVA's mission is simple:

**Give people a little extra power to think, learn, create, build and believe in themselves.**
